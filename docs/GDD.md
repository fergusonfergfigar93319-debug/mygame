## 1. 产品定位与设计支柱

**一句话**：横屏 16:9 的 3D 三车道企鹅跑酷。操作要简单，但每一次闪避都要可读、可练、可炫技。局外是温暖的营地重建和伙伴羁绊。

| 支柱 | 含义 | 落地判据 |
|---|---|---|
| **跑得爽** | 手感、节奏和可读性优先于一切（ADR-0005） | 换道跟手，预警清晰；受击后玩家能说出“我哪里做错了” |
| **会越跑越好** | 技巧有回报：完美闪避、擦身、连续换道、冒险路线 | 技巧分能占高手总分的显著比例 |
| **每个主题都不一样** | 六主题各有片段池、机关、Boss 特性、光照和听感 | 截图、听音都能分辨主题 |
| **温暖的回家感** | 局外是营地重建和伙伴羁绊，不是冷冰冰的数值商店 | 大厅只给一个“下一步”建议 |

**明确不做**（本阶段）：剧情章节、抽卡、体力、联网排行、新货币（ADR-0005，以及技能远征 spec 的范围约束）。

## 2. 目标玩家、会话与成功指标

> 以下是**提案**。代码和文档里目前都没有定义，需要项目负责人拍板（见第 17 节）。

- **目标玩家**：8–35 岁的休闲和中度手游玩家，喜欢《地铁跑酷》式的操作，但更想要“可爱世界观 + 技巧深度”。
- **单局时长**：普通难度 2–4 分钟。第一只 Boss 在约 100 秒出现（见 4.2），一局应至少覆盖 2 个主题和 1 场 Boss。
- **单次会话**：3–5 局，每局之间在大厅停留 30–90 秒（领任务、升级、看图鉴）。
- **建议 KPI**（需要埋点，目前没有）：

| 指标 | 目标 | 用来判断 |
|---|---|---|
| 首局完成率（撑过新手段） | ≥ 90% | 新手期是否过难 |
| 首局第一次受击的平均距离 | ≥ 250 m | 前 30 秒是否公平 |
| D1 / D7 留存 | 40% / 15% | 局外循环是否有拉力 |
| 平均每会话局数 | ≥ 3 | “再来一局”的冲动 |
| 首只 Boss 击败率（普通） | 55–70% | Boss 难度 |
| 死因分布 | 单一障碍类型占比 ≤ 30% | 是否有“不公平杀手” |

## 3. 核心循环

```
大厅（唯一建议）→ 选模式/难度 → 跑酷局
   ↑                                   ↓
营地建筑/升级/羁绊/图鉴  ←  RunOutcomeRouter.Apply（唯一结算事务）
```

- **秒级**：换道、跳、滑、冲刺，收鱼干，完美闪避。
- **十秒级**：片段（2–3 波）、路线选择（安全/冒险）、主题机关（预警 → 生效 → 奖励）。
- **分钟级**：主题切换（52 s）、Boss 战、共鸣、旅途札记三选一。
- **跨局**：营地升级、建筑重建、伙伴羁绊、主题精通星级、契约、图鉴、每日任务/签到/每日挑战。

大厅只给**一个**建议，优先级：可领取目标 → 新发现 → 可重建建筑 → 可买升级 → 新旅程（`G/Growth/GrowthRecommendation.cs`）。

## 4. 一局的时间线

### 4.1 模式

| 模式 | 说明 | 机关首发 / 上限 / 基础概率 |
|---|---|---|
| 故事 Story | 默认模式（名义上的剧情章节按 ADR-0005 后置） | 150 m / 3 次 / 0.42 |
| 无尽 Endless | 纯跑分 | 100 m / 无限 / 0.52 |
| 每日 Daily | 当日决定开局主题 + 种子；Boss Rush，**不刷普通障碍**；当前切图入口未排除 Daily | 120 m / 8 次 / 0.58 |

- 每日主题 = `ThemeCycle[(Year×367+DayOfYear)%6]`（`G/RunSession.cs`）。

### 4.2 普通难度的时间线（估算）

按 v(d) = min(32, 10 + 0.014·d) 估算，时间为距离的积分，而不是直接用末速度相除。封顶距离 dc = (vmax−v0)/k；封顶前 t(d) = ln(1+kd/v0)/k，封顶后 t(d) = ln(vmax/v0)/k + (d−dc)/vmax。以下排除冲刺、慢动作、暂停、教学等待和切图过渡，是局内有效运行时间的解析基准，不是玩家实测分布。

| 时间 | 距离 | 事件 |
|---|---|---|
| 0 s | 0 m | 按玩家选择的主题开场；新手期按 LaneWeave → JumpArc → SlideTunnel → RewardRun 轮换，能力达成可提前毕业，3 局是兜底上限 |
| ~5–15 s | 100–150 m | 首个主题机关窗口（无尽 / 故事） |
| ~17.6 s | 200 m | 移动敌人开始具备生成资格（新手期抑制） |
| ~19.2 s | 220 m | 首个路线调度资格；真正选择还需经过决策段，札记在选择结算后出现；新手期抑制 |
| ~28.5–37.9 s | 350–500 m | 碎裂墙、定时门解锁；500 m 里程碑；移动敌人概率在 500 m 升到 24% |
| ~51.3 s | 750 m | 移动栅栏开始具备生成资格 |
| 52 s | ~765 m | 首次主题切换请求（冰湖开局时转雪松）；实际提交等待路线、机关、Boss 与奖励尾部释放 |
| ~83 s | ~1570 m | 达到最高速 32 m/s |
| **~103 s** | **2200 m** | **第一只 Boss**（切主题暂停，直到 Boss 结束） |
| 其后 | 每 ≥ 2100 m（≈ 66 s） | 后续 Boss |

各难度第一只 Boss 触发距离对应的时间：轻松 221.55 s、普通 102.73 s、困难 62.45 s、专家 43.01 s。轻松无加速基准长于四个 52 s 请求周期，但安全等待和过渡使实际切图次数不能据此直接推算。生成资格不等于攻击起手，Boss 仍有登场与预警阶段。

> ⚠ 这组估算暴露了一个节奏问题，见 15.3。

## 6. 难度曲线

来源：`G/DifficultyPreset.cs:48-110`、`PR/Systems/BossSystem.cs:510-642`。

| 参数 | 轻松 | 普通 | 困难 | 专家 |
|---|---|---|---|---|
| 起始 / 最高速度 (m/s) | 7 / 22 | 10 / 32 | 13 / 40 | 16 / 52 |
| 速度斜坡（每 m） | .008 | .014 | .020 | .027 |
| 首 Boss / 间隔 (m) | 3600 / 3200 | 2200 / 2100 | 1600 / 1700 | 1300 / 1400 |
| Boss 招式间隔 (s) | 3.2–5.0 | 2.4–3.6 | 1.8–2.8 | 1.4–2.2 |
| 分数倍率 | 0.75 | 1.0 | 1.5 | 2.0 |
| Boss 节奏 × / 间隔 × | 1.2 / 1.3 | 1.0 / 1.0 | .92 / 1.28 | .85 / 1.35 |
| 危险窗口比 / 预警比 | .28 / .92 | .32 / .85 | .38 / .78 | .42 / .70 |
| 破绽概率 | .72 | .55 | .42 | .35 |
| 片段最小危险延迟 (s) | .85 | .75 | .65 | .60 |
| 每日 / Boss Rush 首 Boss / 间隔 (m) | 420 / 720 | 380 / 680 | 340 / 640 | 280 / 560 |

- 实际 Boss 间隔 = max(900, 间隔 × 间隔倍率)。
- 实际招式间隔下限 = max(1.3, min × 节奏倍率)，上限 ≥ 下限 + 0.4。
- 预警时长不低于 0.85 s。Boss 血量带来的攻击性**只压缩招式之间的空档**（×1.0 / 0.88 / 0.76），**不缩短预警**。

## 7. 计分与技巧系统

### 7.1 基础得分（`PR/RunnerTuningConfig.cs`、`PR/Systems/WorldDirector.cs`）

| 来源 | 规则 |
|---|---|
| 距离 | 每米 1.8 分（星光加分时 ×1.35） |
| 鱼干 | 每条 10 分 + 1 鱼干（双倍鱼干时 ×2） |
| 鱼干连击 | 每条再加 2×连击，上限 36；连击窗口 1.15 s；每 3 条升一档 +0.08×，最多 5 档（1.4×） |
| 里程碑 | 每 500 m 给 15+5n 条鱼干，分数 = 鱼干 × 5 |
| 完美连击 | 25 + 10 × 连击数 |
| 道具连用 | 3.5 s 内连续拾取，倍率上限 2.5× |

### 7.2 技巧分（技巧链：窗口 2.5 s，倍率 1+0.25(n−1)，上限 3×）

| 动作 | 分值 |
|---|---|
| 完美闪避 PerfectDodge | 100 |
| 连续换道 LaneChain | 35 |
| 空中收集 AirCollection | 60 |
| 无伤片段 NoHitSegment | 180 / 片段（机关完美节拍 90） |
| 冒险路线 RiskRoute | 140 |
| Boss 反击 BossCounter | 250 |
| 擦身而过 NearMiss | 40 |

### 7.3 结算（`G/RunOutcomeRouter.cs:72-91`，唯一事务）

```
鱼干 = max(原值, round(原值 × 营地鱼干加成 × 双倍券(2/1) × (1+团团羁绊))) + Dror 援助
分数 = round(原值 × 营地分数加成 × 分数券(1.5/1) × 难度倍率)
Dror 援助 = 本局冒险路线 > 0 且命中概率 ? 4 + min(12, 2×冒险数) : 0
```

## 8. 障碍、片段与节奏

**权威**：碰撞判定只来自 `ObstacleColliderSpec` + `RunnerHitResolver`。视觉永远不改判定。

### 8.1 障碍解锁（`PR/Systems/SegmentSpawner.cs`）

| 障碍 | 规则 |
|---|---|
| 移动敌人 | 200 m 后 13%，500 m 后 24% |
| 特种障碍 | 概率 0.08 + 距离/5000 |
| 高刺 TallSpike 30% / 中栏 MediumBarrier 22% | 只在 HazardRhythm 片段，300 m 后 |
| 定时门 TimedGate | 500 m 后 10% |
| 移动栅栏 MovingBarrier | 750 m 后 7% |
| 宽障碍改为宽滑门 WideSlideGate | 400 m 前 25% |
| 宽墙升级为碎裂墙 ShatterWall | 350 m 后 30% |

### 8.2 片段池（`PR/Systems/RunnerSegmentCatalog.cs`）

每个片段 2–3 波。六主题分别有 14 / 13 / 13 / 14 / 13 / 13 个片段（冰湖 / 雪松 / 极光 / 雾堤 / 海洋 / 天空）。
各主题的偏向：极光 JumpArc ×3，雾堤 SplitGate ×3，天空 SlideTunnel ×3。PatternKind 共 9 种，见 `CURRENT_DESIGN.md`「障碍与片段」。

### 8.3 节奏原则

- 片段内：危险 → 喘息 → 奖励，三拍循环。`MapMechanicDirector` 用 PressureDebt / RewardDebt 做补偿（见 11.2）。
- 同一屏最多出现一个“新”威胁。新障碍首次登场时必须在安全位置单独呈现。
- Boss 前 180 m 不安排路线事件。

## 10. 路线事件与旅途札记

- 首次 220 m，之后间隔 ≥ 280 m，决策段 72 m；Boss 前 180 m 内不出现；切主题时取消进行中的路线。

|---|---|---|---|

| 雪松 | 雪松呼救 / 遗迹岔口 | 160/4 · 150/3 | 420/7 · 350/8 |

| 宽幅磁场 | 磁铁半径 +18% | ✅ |
| 鱼干挎包 | 路线鱼干 +12% | ✅ |

| 软垫护盾 | 护盾宽限 +0.18 s | ✅ |
| 冰纹护甲 | 受击无敌 +0.12 s | 已接入障碍与 Boss 防御解析后的无敌时长 |
| 伙伴口哨 | 伙伴救援事件分数、鱼干奖励 +15% | 已接入 CompanionRescue 选择奖励；不增加遇见概率或 Dror 援助概率 |

- **契约**（每局用种子抽 1 个）：连续 3 次完美；2 次无瑕；共鸣期间拿 20 条鱼干；1 次标志事件；800 m 前技巧分达 1200。

### 12.2 战斗规则（`PR/Systems/BossSystem.cs`、`BossEncounter.cs`）

- 每个招式走四拍：Windup → Telegraph → Strike → Recovery。
- **3 击击败**。只能在破绽窗口（1.6 s × 主题系数）内攻击：冲刺撞击（车道容差 ×1.2）或护盾撞击（×1.5），Boss 需在 Z ∈ [8.5, 17] 范围内。连续 4 个招式没有破绽时强制给一次破绽，否则按破绽概率随机。

- 奖励：每击 +150 分；击败 +25 鱼干、+800 分。速杀评级 S/A/B/C（用时 ≤ 36% / 60% / 84% 窗口），额外奖励系数 1 / .72 / .45 / .15 乘该难度的鱼干/分数上限。

## 18. 权威边界速查

| 领域 | 唯一权威 | 不得 |
|---|---|---|
| 碰撞判定 | `ObstacleColliderSpec` + `RunnerHitResolver` | 让 VFX 或模型尺寸改变判定 |
| 存档与成长写入 | `RunOutcomeRouter.Apply` / `GrowthTransaction` | 在 UI 里直接写 PlayerPrefs |

| 难度数值 | `DifficultyPreset` + `BossSystem` 难度表 | 散落在各系统里的魔法数 |
| 片段 | `RunnerSegmentCatalog` | 在 Spawner 里硬编码新片段 |
| 验证 | `tools/Verify*.ps1` + `CompileFullRoslyn.ps1` | 声称 Android 实机已通过 |
