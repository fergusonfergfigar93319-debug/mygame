# 营地升级时长预览对齐设计

## 目标

让营地强化页展示的道具基础时长与当前跑酷配置一致，并说明每项升级实际影响的道具。保留现有跑酷数值，不改成长曲线、道具概率、主题加成、连击或札记效果，也不改存档格式。

## 现状与范围

`RunnerTuningConfig.Default()` 是跑酷基础时长的默认来源，`PenguinRunnerGame` 将它转换成运行时的 `RunnerPowerUpTuning`，由 `PickupSystem` 按拾取道具和营地等级计算时长。营地页 `CampUpgrades.FormatEffectAt()` 则另写了一组公式，造成预览与默认游戏配置不一致。

需要对齐的当前基础值（秒）：

| 强化 | 实际影响的道具 | 基础时长 | 每级增加 |
|---|---|---:|---:|
| 冲刺 | 鱼干冲刺 | 5.5 | 0.9 |
| 磁针 | 极光磁针 | 7.0 | 1.4 |
| 团团 | 团团护盾 / 各类滑翔 | 4.5 / 6.0 | 0.8 / 0.7 |
| 极地直觉 | 星光 / 双倍鱼干 / 沙漏 | 7.5 / 6.0 / 4.2 | 0.8 / 0.65 / 0.55 |

实际拾取时可能再乘连击、札记等局内效果；营地页只承诺**基础时长**。既有主题道具的固定时长增量和其他道具效果不属于本次平衡调整。

## 方案与取舍

1. 只手工改营地页的四条预览公式：改动最少，但继续保留重复数字，之后容易再次漂移。
2. 营地页从 `RunnerTuningConfig.Default()` 读取实际默认参数，运行时仍使用原有配置与公式：展示值自动随默认调参更新，且不改变当前玩法。**采用此方案。** 当前跑酷场景没有序列化独立的时长覆盖；如后续在 Inspector 为跑酷场景设置不同的时长参数，应另行提供大厅与跑酷共用的配置来源。
3. 引入跨场景共享的 ScriptableObject 时长资产：可支持逐场景/全局调参，但需改场景装配与配置资产，超出本轮小范围修正。

## 展示与数据流

- `CampUpgrades.FormatEffectAt()` 读取 `RunnerTuningConfig.Default()`，格式化请求等级下的冲刺、磁针、护盾、滑翔、星光、双倍鱼干和沙漏基础时长。
- 团团升级同时显示护盾与滑翔基础时长；极地直觉显示当前已承诺的道具率加成及其影响的三种道具时长。
- 对时间预览标注“基础”，文案明确团团与极地直觉分别影响哪些效果；鱼干、得分、道具概率升级保持现有计算。
- `PickupSystem`、局内倍率、场景和存档不做玩法改动。

## 验收

- 新增使用真实 `RunnerTuningConfig` 与 `CampUpgrades` 的独立回归测试，验证所有营地等级 0–5 的展示值都匹配基础配置，并校验团团/极地直觉的多重效果提示。
- 先观察测试在现有预览公式上按预期失败，再完成修正并通过测试。
- 重跑与改动相关的静态门禁和全量 Roslyn 编译；报告 Unity 或 Android 实机未运行时，不声称这些环境已验收。

## 非目标

不重新平衡道具、冲刺冷却、 Boss 节奏、难度、鱼干经济、玩家等级、建筑作用或每日挑战；不改存档、Inspector 配置资产、排行榜或主题事件。
