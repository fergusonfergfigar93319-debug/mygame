# 0005. 剧情后置，先打磨游玩内容与操作体验

## Status

Accepted（2026-09-21）

## Context

- `docs/STORY.md`、大厅「下一章」和图鉴「击败高松鹅」仍按三章冒险承诺终局。
- `docs/CURRENT_DESIGN.md` 的现行产品是短局横屏无尽跑酷；玩家明确选择先优化局内内容和操作体验，剧情以后再设计。
- 若继续按章节叙事改代码，会把鱼干、营地建筑和解锁阈值缠进尚未成立的终章，手感问题会被继续推迟。

## Decision

- 本阶段只改 **游玩内容**（片段、障碍、道具、Boss 作为遭遇）和 **操作体验**（输入、位移、镜头、反馈）。
- `docs/STORY.md` 的章节结构、高松鹅终章战、大厅「下一章」作为叙事承诺，一律后置；不为它们新增系统或改判定。
- 新手期内第一次道具固定为鱼干冲刺，只展示一种明确效果。

## Consequences

- 更容易：手感与片段节奏可以单独验收，不必等世界观闭环。
- 更难：图鉴与大厅里仍残留章节措辞，直到叙事阶段才收口。
- 明确不做：本 ADR 不引入新剧情关、不把高松鹅做成可打的终章 Boss、不把商店围巾/帽子接到局内换装。
